# EasySub2api 0.0.86

- CC Switch 导入统一使用默认 Sub2API 用量查询脚本，覆盖 Claude、Codex、Gemini、Grok、OpenCode、OpenClaw 和 Hermes。
- 修复导出端点已带 `/v1` 或尾部斜杠时用量查询地址重复拼接的问题，同时保留部署子路径。
- 完善钱包余额、配额总量与已用量、无限额度及无效 Key 状态的展示；保留积分或上游返回的单位。
- 保持用量查询默认启用及原有自动刷新间隔，并继续支持自定义用量脚本。
- 模型转发统一由分组配置，支持精确匹配及末尾 `*`，在上游账号选择前生效。被转发的来源模型从模型发现列表隐藏，OpenAI 请求按实际转发模型计费。
- 完善 Responses Lite 的最终请求规范化，设置 `reasoning.context: "all_turns"` 和 `parallel_tool_calls: false`，将 namespace 声明移入 `additional_tools`，保留工具选择和大整数精度。
- Lite 工具搜索要求显式使用客户端执行模式，并拒绝不合法 JSON。补齐普通 HTTP、透传 HTTP 和 WebSocket 桥接的回归覆盖。
- 修复映射到 GPT-5.5 的 OAuth 请求兼容性，并保证最终请求体、重放请求体和长度一致。

升级时执行迁移 292，将已绑定分组的 OpenAI 账号转发规则迁入对应分组。相同来源冲突时，已有分组规则优先，其次按分组内账号优先级选择。未绑定分组的账号保留原规则。

已导入 CC Switch 的配置需重新导入，才能使用新版查询脚本。
