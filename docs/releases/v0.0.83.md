# EasySub2api 0.0.83

- OpenAI 账号新增独立的模型转发配置，可动态添加、修改和删除多条规则，支持精确匹配与末尾 `*` 通配符。
- 转发规则按当前上游账号独立生效，命中规则的来源模型无需加入账号白名单；支持普通转发与自动透传，并将规则保留到调度缓存及模型列表。
- 命中账号模型转发后，按实际发送到上游的最终模型价格扣除积分，避免使用原请求模型或渠道中间模型的价格。
- API Key 导入 cc-switch 的默认 Codex 模型更新为 `gpt-6.1-sol`，附带子代理默认模型 `gpt-6.1-terra`。

本次无需新增数据库迁移。已有账号在未配置模型转发时沿用原有行为；目标模型需由上游支持，并配置相应定价。
