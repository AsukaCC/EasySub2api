# EasySub2api 0.0.60

## 积分与退款

- 统一充值及赠送积分的可用余额，允许奖励追回后形成负余额，欠额抵扣后才能继续消费。
- 取消订单退款的 7 天限制，保留订单归属、支付状态、渠道能力及剩余本金校验。
- 退款按累计比例追回订单赠送积分及该订单产生的邀请返佣，失败时恢复预留余额，重复请求保持幂等。
- 赠送积分永久有效，已发生的历史过期扣除不补回；充值促销保留比例赠送，移除重复的固定赠送模式。
- 管理端用户管理新增积分变动查询，支持用户、积分来源、增减方向及日期筛选。

## 模型与账户

- 更新 TypeSafe System One、Grok CLI 及 GPT-6.1 相关兼容处理与思考强度校验。
- 模型归因支持从 API Key 账户获取上游模型，选择 Chat Completions 或 Anthropic Messages 协议及思考强度。
- 更新 ModelTrace 题库与自动测试，管理员可查看常规格式的测试用量记录。
- 增加每半小时模型归因定时测试，归因历史及相关测试记录保留 24 小时。
- 移除模型限制中的本地“同步最新支持模型”入口，保留从上游获取模型的能力。

## 修复

- 同步上游 v0.2.13：TypeSafe 创建账户时允许启用账单探测，官方域名直接返回不支持探测。
- 同步上游 v0.2.13：请求处理中删除 API Key 后，其余钱包、订阅及账户结算继续提交。
- 补齐 Gemini 格式提示词审计，覆盖系统指令、对话及批量请求文本，排除媒体数据。
- 修复 Grok OAuth 模型别名进入 Codex 归一化分支而导致上游路由错误的问题。
- 修复历史充值订单未填写独立币种字段时无法采用订单快照币种的问题。
- 修正支付与账户测试中未同步的字符串 ID、钱包接口及页面断言，并将相关回归测试加入 CI。

## 升级说明

本版本包含迁移 281 至 283。升级前停止旧应用写入及旧赠送积分过期任务，备份数据库，再启动新版本完成迁移。请勿混用新旧实例写入钱包，也不要直接回滚至不支持负赠送余额及永久赠送的旧版本。

本地验证包含聚焦后端单元测试、前端回归测试、类型及构建检查。旧 PostgreSQL 集成测试夹具仍存在字符串 ID 适配错误，完整数据库集成测试尚未通过；没有连接生产数据或执行生产迁移。
