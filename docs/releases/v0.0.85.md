# EasySub2api 0.0.85

- 新增 GPT-6.2 Astra / Sol 的模型目录、别名、Codex 能力声明及定价支持，覆盖长上下文、缓存与 Ultra Fast 价格时段，并保留显式自定义价格和零价。
- 分组新增强制 Ultra Fast 配置，支持 Astra / Sol，优先级为 Ultra Fast > Fast > 客户端；字段贯通分组复制、鉴权与调度缓存。
- Codex 与 CC Switch 导出默认模型更新为 `gpt-6.2-sol`，支持编辑主模型、独立子代理模型及 WebSocket 开关；默认子代理跟随主模型。
- 选择性适配上游 v0.2.22：改进 Codex 外部上下文、工具声明及 JSON Schema 兼容性，保留协议转换中的加密工具内容与合法 metadata。
- 修复 Gemini 并行工具调用和结构化输出，增加 Carbon 思考配置与模型目录；改进 Grok 服务端搜索和错误识别，以及 Bedrock 错误、限流和部分用量处理。
- 修复 Kimi 月度配额、Fable 限流恢复及周窗口观测，改善未知用量和刷新失败的界面展示；分组费率/RPM 批量同步增加事务与去重。
- Vertex 支持 us/eu 多区域端点、模型区域回退及已有缓存的区域路由；实际多区域请求的默认 token 定价加价 10%，保留显式自定义价格优先级。
- 改善 SSE keepalive 后的错误返回、TCP keepalive、首输出缓冲及动态 HTML 缓存策略。原生 `image_generation` 工具按客户端声明透传，不自动注入。

## 升级说明

- 首次启动执行迁移 `291_group_force_openai_ultrafast.sql`；新增字段默认关闭。
- GPT-6.2 Ultra Fast 在 2027-03-01 08:00 UTC 前按 3 倍、此后按 6 倍计算；Fast / priority 按 2 倍计算，现有钱包及幂等结算规则继续生效。
