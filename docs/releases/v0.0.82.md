# EasySub2api 0.0.82

参考 Sub2API v0.2.20 / v0.2.21，按 EasySub2api 现有业务适配。

- 修复 Responses 工具调用重建丢失 namespace、encrypted_function_args，补全非流式终态、instructions 回显及元数据事件失败切换。
- 完善 WebSocket 后续轮次保护、搜索能力、HTTP 桥接指纹与首 token 统计。
- 为请求体内存、上下游读写、SSE、后台任务和会话缓存增加边界，修复异常路径并发槽位释放与刷新令牌并发复用。
- 支持 Claude Fable / Mythos 5.2，补全 Gemini / Antigravity 思考与工具媒体兼容性。
- 新增 OpenAI 30m / 12h 缓存写入用量和独立价格，接入现有积分结算及分组/渠道/账号价卡；显式零价有效。
- 支持生图账号按 1K / 2K / 4K 分流，保留 30 分钟会话优先与溢出绑定保护。
- 新增默认关闭的管理 MCP、OAuth 授权/撤销页面、管理员密钥细分权限及全权模式确认。
- 新增注册邮箱精确黑名单，完善账号配额刷新、用量导出、客户端导出及中英文翻译。
- EasyPay 可配置退款成功码 0 或 1，继续使用原有退款与积分钱包。

保留 UUID、gpt-5.6-sol 默认模型、停用模型限制、Key 调度、每请求积分结算、可取消的空闲归因测试、7 天测试记录和账号 Codex 积分快照。充值倍率固定为 1。

新增迁移 288–290，升级时自动执行。大用量表的并发索引创建可能延长首次启动时间。管理 MCP 需显式配置 MCP_PUBLIC_URL；默认关闭。请求体预算配置键为 gateway.request_body_memory_budget_bytes。
