# EasySub2api 0.0.87

- 修复模拟 Codex 身份时自动启用 Responses Lite 的问题；普通及透传 HTTP 请求保持客户端选择的协议，未启用 Lite 时保留原生 `web_search` 工具。
- 仅在请求明确启用 Lite 时执行对应的工具和请求体规范化，继续保留 namespace 工具、大整数精度及显式请求头。
- 显式 Lite 请求使用不支持的工具时，统一返回清晰的 `400 invalid_request_error`，提示改用完整 Responses 或兼容 Lite 的请求，避免重复写入错误响应。
- 区分客户端 Lite 校验失败、账号请求头覆盖和底层读写错误，并补齐 HTTP、透传、metadata 启用及断线重试的回归检查。
