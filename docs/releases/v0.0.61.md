# EasySub2api 0.0.61

## 模型归因修正

- 模型归因固定当前被测试账号，下拉框改为选择当前管理员的 API 密钥，不再选择上游 API Key 账号。
- 只提供有效且分组支持当前账号平台的 API 密钥；选择接口仅返回名称和标识，不返回密钥内容。
- 模型列表查询、手动测试和每半小时定时配置均携带 API 密钥标识，测试用量记录关联对应密钥和分组。
- 后端校验密钥归属、状态、有效期、额度和分组权限，每轮采样前重新校验；密钥被删除或停用后停止后续采样。
- 修复切换密钥时旧模型列表覆盖新选择的问题，补充无可用密钥及定时密钥失效提示，并更新中英文文案。

## 升级说明

- 本次无新增数据库迁移。旧定时测试配置需要重新选择 API 密钥并保存，失效密钥不会自动替换。
- 保留管理员测试不扣除钱包或密钥额度、测试记录保留 24 小时的规则。
- 从 v0.0.60 之前升级时，仍需遵循 v0.0.60 的积分与退款迁移说明。

## 验证

后端模型归因聚焦测试、后端编译、Go 静态检查、前端类型检查、14 项交互测试及桌面/手机模拟页面检查通过。未连接生产数据或调用真实上游。
