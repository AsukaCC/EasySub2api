# EasySub2api 0.0.41

本版汇总自 v0.0.40 以来的网关、计费、管理功能和账号保护改造。

## 新增功能

- 新增账号保护策略管理，支持预览、应用、切换、确认关闭、还原和批量启用。策略变更原子提交，普通保存及凭据刷新保留受管字段和身份种子。
- 提供 legacy、mode1 v3、mode2 及诊断策略：分别采用 session + nodejs24、device + 标准传输、full + nodejs22。管理员已配置的正数并发上限保留；无有效上限时分别补齐 16、16、8。
- 新增请求语义完整性检查 off/observe/enforce。mode1 v3 默认 enforce，其他受保护 OpenAI OAuth 类账号默认 observe；检查 input、instructions、reasoning、tools、模型及预算等关键字段，阻止有损转换时不向上游发送、不冷却账号。
- 新增 OpenCode Zen / GO 平台及多协议路由，接入账号测试、模型目录、额度窗口和限流恢复。
- 新增统一站点计费模式：仅充值、仅订阅、充值与订阅并存，联动页面入口、套餐列表及后端下单校验。
- 新增订阅批量延期、额度重置、撤销和恢复，API Key 部分字段批量编辑，以及逐项反馈的用户批量删除。
- 新增用户动态优惠窗口展示，以及按指定请求 ID 启用、限制次数并脱敏的出站 HTTP 请求头诊断。

## Bug 修正

- 修复实时语音 Live 会话漏计费：创建时保存计费快照，结束时执行幂等结算，失败可重试，避免重复用量记录及倍率被后续配置覆盖。
- 修复图片缓存读取 token 与普通图片输入、文本缓存混算，支持独立图片缓存价格并统一用量解析和渠道价格覆盖。
- 修复 WS 并行线程、子任务、重连及换号重试的执行作用域隔离，连接池等待者在连接变化后重新选择可用连接。
- 补齐粘性逃逸选择闭环：优先尝试其他合格账号，包括等待其他账号；没有替代方案时才回退原账号，不绕过已有排除条件和分组隔离。
- 修复 Antigravity OAuth 的 Gemini 兼容转发，补齐 Setup Token 的协议、图片及测试路径。
- 修复 DeepSeek 未配置映射时的模型资格校验、Codex 最大上下文信息同步，以及 OpenCode 用量重置窗口处理。
- 修复关闭域名白名单时连带绕过协议及私网限制的问题；跨标签页复用刷新令牌时校验登录用户一致性。
- 将分组、代理和兑换码统计接入真实查询；兑换码分页导出不再受单次大分页截断，无法观测的代理历史指标明确返回空值。
- 修复用量导出筛选不一致、重置 Key 额度后的状态同步、代理部分导入后的列表刷新、监控刷新间隔及账号资料错误提示。
- 修复仅充值模式下残留的计费类型筛选，历史订阅用量和导出仍保留；修复前端翻译原始键显示并对齐相关回归测试。

## 身份与兼容性优化

- 默认 Codex UA/originator 改为 codex-tui，保留 OS、架构和终端后缀；移除 TUI 到 CLI 的归一逻辑，保留合法显式身份配对，内置版本不低于 0.154.0。
- 稳定版和预发布版统一执行格式及最低版本校验，不再要求预发布放行开关；自动同步仍沿用原有发布源。
- 出站 session、conversation、thread、installation、window 等标识按上游账号/凭据命名空间稳定派生，不混入下游 API Key。影子账号使用母账号身份，换号重新投影，OAuth 刷新不改变身份来源。
- HTTP 身份补齐按具体路径应用 responses=experimental；Messages/Chat 桥接不补回 originator；WS 保留独立协议协商 token。不再从原始 device_id 独立补齐 installation 请求头。
- Claude CLI 新建和缓存指纹均执行版本下限检查，保留更高版本、后缀及既有 Stainless 合并规则。
- TLS 模板接入 HTTP、WS 和探针，连接复用键包含实际模板摘要；全局 TLS 指纹开关仍优先，诊断区分配置、有效传输和未观测状态。
- 优化图片原生端点及 Responses 回退、流式编辑事件、实际图片尺寸和 1K/2K/4K 档位；统一前端样式、弹窗及浮层层级。

## 模型下架

- GPT-5.4 和 GPT-5.5 整个家族退出新流量，包括 mini、nano、pro、日期、别名、大小写及带提供商前缀的变体。
- 模型列表、Codex 清单、渠道可用性及公开价格隐藏下架模型，HTTP/WS、透传和映射目标均执行检查，不静默替换用户指定的下架模型。
- 新默认账号测试、compact 和客户端配置示例使用 gpt-5.6-sol，轻量 Messages 默认映射使用 gpt-5.6-luna。
- 历史用量、模型名称、账单、导出和内部历史定价保留；不重算账单，不改余额，不删除持久化数据。

## 升级注意事项

- 升级前备份数据库。自 v0.0.40 起包含迁移 274、275，扩展 OpenCode 平台约束并增加图片缓存读取价格列；账号保护元数据使用 extra JSON，不额外增加数据库列。
- 新账号默认启用适用的保护；不支持身份保护的平台及凭据影子仅补齐通用并发保护。已有账号不自动迁移，需要管理员手动或批量启用。
- 出站身份变化可能使既有上游会话无法无缝续接，需要建立新会话；不要通过清空 Redis 或删除数据卷处理。
- 已保存的账号/分组模型映射及环境变量不会自动改写，请检查下架模型目标，尤其是 GATEWAY_OPENAI_COMPACT_MODEL。
- 安全默认值收紧，使用自定义域名、内网或 HTTP 上游的部署需核对 URL 安全策略；WS 默认连接池系数由 1 提升到 5，仍受连接数上限约束。
- codex_allow_prerelease_version 和 disable_codex_originator_normalization 仅兼容读取，不再影响行为；disable_codex_identity_enforcement 仍独立有效。
- TLS 指纹是传输策略，完整性检查是请求体保护，不保证上游模型质量、账号接受率或性能提升。本版未引入严格 RPM、自适应并发、健康熔断、随机代理或插件系统。
