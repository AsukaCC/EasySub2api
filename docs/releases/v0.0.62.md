# EasySub2api 0.0.62

## 模型归因修正

- 固定当前被测试账号，直接选择该账号支持的上游模型，移除 API 密钥选择框。
- 移除模型归因专用的本地 API 密钥列表接口、归属及分组校验和依赖注入，测试使用当前账号保存的上游凭据。
- 模型查询、手动测试及定时配置不再要求或提交 API 密钥标识。
- 保留请求格式、思考强度、每半小时定时测试，以及管理员用量记录和 24 小时保留规则。
- 旧定时配置中的 API 密钥字段会自动忽略，即使对应密钥已被删除，也可继续按账号与模型执行；无需重新绑定密钥。

## 升级说明

本次无新增数据库迁移。从 v0.0.61 升级无需重新配置定时任务的密钥。管理员权限保护及账号上游模型、参数校验继续生效。

## 验证

模型归因相关后端测试、后端编译和静态检查、前端类型检查、14 项交互测试及桌面/手机模拟页面检查通过。未连接生产数据或调用真实上游。

额外扩大测试范围时，旧 Codex/TLS 用例仍存在失败，本次未修改这些无关逻辑，不声明完整测试套件全部通过。
